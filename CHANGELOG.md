# Changelog

## [0.5.0] - 2026-11-06

### Added
- WoW Forever support (interface 16001)
- Quest log check uses C_QuestLog on WoW Forever

## v0.1.0

- Initial release
- Track quest completion for all Classic and TBC dungeons
- Tabbed UI with dungeon groups and quest status
- Prerequisite quest chains shown indented
- Heroic quest tags
- Faction filtering
- Wowhead link popup for each quest
- Summary tab with overall progress
- Minimap button and keybinding support
- Config options for display preferences
